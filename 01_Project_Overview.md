# Project Overview

## Objective

This project is a Product Management case study for Zepto.

**North Star Metric**

> Increase the percentage of Monthly Active Customers who purchase
> products from at least one new category every month.

## Product Idea

Introduce two new features into the existing Zepto app: 1. My Space 2.
Buddies

These features help users discover complementary products from new
categories while shopping with minimal effort.

## Important

-   This is **NOT** a redesign of Zepto.
-   Use the existing Google Stitch React screens as the UI foundation.
-   Do not recreate or redesign the UI.
-   Only add functionality, navigation and data.

## Prototype Goal

-   Cross-category recommendations
-   Shopping missions
-   Shared shopping
-   Dynamic product pages
-   Working navigation

This is a high-fidelity prototype, not a production application.
